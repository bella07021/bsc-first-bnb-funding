# CEX 热钱包首笔 BNB 到账关系与分组

公开网页：<https://bsc-first-bnb-funding.vercel.app>

批量扫描 BSC 普通 EOA 地址收到的 CEX 热钱包普通原生 BNB 入账。每个“具体热钱包地址 → 接收地址 → BNB”关系分别保留第一次成功、金额大于 0 的到账，并显示：

- 北京时间（UTC+8）到账时间
- 精确 BNB 金额
- 来源 CEX 热钱包标签与完整地址
- 交易哈希及 BscScan 链接

前端单次最多接收 300 个地址，按每批 20 个依次查询，并实时显示批次、完成数量和百分比，最后统一汇总结果。

到账时间分组按具体 CEX 热钱包地址分别计算，同一交易所的不同热钱包不会合并。组内按该热钱包与各接收地址的首次到账时间升序排列，相邻间隔不超过 20 分钟且连续至少 2 个地址。一个接收地址收到过多个 CEX 热钱包的 BNB 时，会分别显示多条关系。页面与 Excel 导出会同时显示组内地址数和对应的原始查询序号。

不包含 Internal Transaction。查询失败或数据覆盖不完整时会显示失败，不会误报为“无 CEX 入账”。

## 本地运行

```bash
npm install
npm run dev
```
